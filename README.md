# Fairyland-Cake-Co.
Website project for Fairyland Cake Co. Featuring product galleries ,custom cake options, and customer review links.

Fairyland Cake Co. is alocal small business artisan bakery specializing in custom cakes and dessert spreads. The site provides an organized menu high -resolution media galleries, and a structured order inquiry form to steamline client bookings.

## features
semantic HTML5
LAYOUT CLEAN, ACCESSIBLE STRUCTURE WITH SEMANTIC TAGS <header></header>,<footer></footer>,<section>,<nav></nav>,<h2></h2>

##Custom Order Form Interactive inquiry form mapping event dates, cake sizes, flavors and dietary needs.

## Responsive Styling
Color palette, Pastel pink,warm cream and deep charcoal
